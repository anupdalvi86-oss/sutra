# Sutra

Sutra is an AI company operating system: a governed network of AI agents that can plan, build, test, secure, market, sell, and financially manage projects under founder-defined authority.

## Core stack
- Hermes — agent runtime
- Railway — hosting
- Supabase — shared company state/source of truth
- GitHub — engineering workflow
- Codex — coding worker
- Telegram — founder command interface

## Governance
- Founder retains ultimate authority.
- Agents operate only within explicit permissions and budgets.
- Spending thresholds are configurable policy stored in the company database, not hard-coded prompts.
- Agents cannot increase their own financial authority.
- Material financial, legal, destructive, external, or governance actions follow configured approval paths.
- Important decisions/actions are audit logged.
